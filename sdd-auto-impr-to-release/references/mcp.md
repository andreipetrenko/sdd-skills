# MCP

Этот скилл сам не вызывает Jira и Bitbucket.

Запись и чтение в Jira/Bitbucket — только внутри атомарных скиллов, по их `references/mcp.md`.

## Запрещено

- REST `curl` / `requests`
- спрашивать токены
- GitHub / GitLab / GitVerse API
- выдумывать workspace, slug, номер релиза, репу компонента
- добавлять MCP-шаги, которых нет у атомарных скиллов
