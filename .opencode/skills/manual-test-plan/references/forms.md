# Формы

Подключай только пункты, которые относятся к полям этой задачи.

- Пустая отправка обязательных полей показывает, какое поле не заполнено.
- Недопустимое значение остаётся в поле, сообщение говорит, что исправить.
- Повторное нажатие отправки не создаёт вторую сущность.
- Уход с частично заполненной формы не сохраняет её молча.
- Значение на границе длины принимается, на один символ длиннее — нет.
- Успешная отправка видна без перезагрузки всего сценария заново.
