# Права

Роль бери из `task.role`. Вторую роль бери из `project.roles`, только если она есть.

- Действие из критерия доступно указанной роли и заканчивается ожидаемым результатом.
- Роли, которой действия не положено, не видит его в интерфейсе. Если в diff есть отдельный запрос на это действие, человек проверяет отказ и с этой ролью.
- Прямой адрес сценария без права не выполняет действие.
- Чужие данные этой роли не показываются, если задача про доступ к записи или списку.
