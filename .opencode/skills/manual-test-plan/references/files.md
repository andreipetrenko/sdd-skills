# Файлы

Подключай только если задача принимает или отдаёт файл.

- Файл допустимого типа и размера прикладывается и скачивается тем же содержимым.
- Пустой файл и файл больше лимита отклоняются с понятным сообщением.
- Тип вне разрешённого списка не сохраняется.
- Имя с пробелом сохраняется, повторная загрузка заменяет файл, а не оставляет два, если задача про замену.
