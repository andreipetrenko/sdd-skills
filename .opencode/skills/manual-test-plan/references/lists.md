# Списки

Подключай только если задача меняет список, фильтр, сортировку или постраничный вывод.

- Пустой набор показывает пустое состояние, а не ошибку и не вечную загрузку.
- Один элемент отображается без лишней страницы.
- Фильтр без совпадений даёт пустой результат и не ломает сброс фильтра.
- Сброс фильтра возвращает набор, который был до фильтра.
- Граница страницы не пропускает элемент и не повторяет его на двух страницах.
